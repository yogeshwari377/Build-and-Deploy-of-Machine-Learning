# Dataset Directory

Place the actual Kaggle dataset file here.

### Dataset Details
- **Source**: [Student Performance Multiple Linear Regression (Kaggle)](https://www.kaggle.com/datasets/nikhil7280/student-performance-multiple-linear-regression)
- **Target File Path**: `data/Student_Performance.csv`

### Expected Columns
1. `Hours Studied` (Numeric): Number of hours spent studying by each student.
2. `Previous Scores` (Numeric): Scores achieved by the student in previous tests.
3. `Extracurricular Activities` (Categorical: `Yes` or `No`): Participation in extracurricular activities.
4. `Sleep Hours` (Numeric): Average number of hours of sleep per day.
5. `Sample Question Papers Practiced` (Numeric): Number of sample question papers solved.
6. `Performance Index` (Target, Numeric): Continuous academic performance index score (10 - 100).
